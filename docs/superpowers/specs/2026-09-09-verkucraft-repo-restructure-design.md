# VerkkuCraft Repository Restructure Design

## Overview

Restructure the VEventDrops repository to properly organize it as the VerkkuCraft launcher project — a Minecraft launcher with custom mods and plugins. The `client-mods/mods/` folder becomes the source of truth, and the CI pipeline auto-generates manifest entries from it.

## Current State

The repo contains:
- `src/main/java/com/vevent/` — Old vEvent server plugin
- `fabric-mod/` — Custom title screen mod
- `src/VerkkuCraftLauncher/` — WPF launcher app
- `mods/` — 19 client mod JARs (mix of third-party and custom)
- `manifest.json` — Static manifest with plugins, client mods, shader mods
- `server/` — Docker compose and server config

## Pipeline Changes (release.yml)

### Steps:

1. **Build server plugin** from `server-plugin/custom-plugins/vEventDrops/`
2. **Build custom mods** from `client-mods/custom-mods/fabric-mod/`
3. **Scan `client-mods/mods/`** and **`client-mods/custom-mods/`**:
   - Extract mod name from filename (e.g., `lithium-fabric-0.25.3+mc26.2.jar` → `Lithium`)
   - Calculate SHA256 hash
   - Get file size
   - Build download URL pointing to GitHub release assets
   - Add to `clientMods` array in manifest.json
4. **Scan `server-plugin/custom-plugins/`**:
   - Extract plugin info
   - Add to `plugins` array in manifest.json
5. **Inject secrets** (Tailscale auth key)
6. **Upload all JARs + manifest** to GitHub release

### Manifest Entry Format (auto-generated):

```json
{
  "clientMods": [
    {
      "name": "Lithium",
      "modrinthProjectId": "lithium",
      "version": "0.25.3",
      "fileName": "lithium-fabric-0.25.3+mc26.2.jar",
      "downloadUrl": "https://github.com/.../releases/download/vX.X.X/lithium-fabric-0.25.3+mc26.2.jar",
      "sha256": "...",
      "fileSize": 1234567
    }
  ]
}
```

## Mod Name Extraction Logic

Python script in pipeline to parse filenames:

```python
import re, os, hashlib

def parse_mod_filename(filename):
    """Extract name and version from mod filename."""
    # Remove .jar
    name = filename.replace('.jar', '')
    # Split by common delimiters
    # Examples:
    #   lithium-fabric-0.25.3+mc26.2 → Lithium
    #   fabric-api-0.160.0+26.2 → Fabric API
    #   verkku-title-1.1.0 → VerkkuCraft Title Screen
    parts = re.split(r'[-_]', name)
    # Filter out common suffixes (fabric, mcXX.X, etc.)
    version_pattern = re.compile(r'^\d+\.\d+')
    version = ''
    main_parts = []
    for part in parts:
        if version_pattern.match(part):
            version = part
            break
        if part.lower() not in ['fabric', 'forge']:
            main_parts.append(part)
    display_name = ' '.join(main_parts).title()
    return display_name, version

def scan_mods_folder(folder_path):
    """Scan mods folder and return manifest entries."""
    mods = []
    for f in os.listdir(folder_path):
        if f.endswith('.jar'):
            filepath = os.path.join(folder_path, f)
            name, version = parse_mod_filename(f)
            sha256 = hashlib.sha256(open(filepath, 'rb').read()).hexdigest()
            size = os.path.getsize(filepath)
            mods.append({
                'name': name,
                'version': version,
                'fileName': f,
                'sha256': sha256,
                'fileSize': size
            })
    return mods
```
